## 🎯 What Is FTJIYANA?

</div>

<table align="center">
<tr>
<td width="50%" valign="top">

### 💀 The Problem

- ❌ Subdomain tools scattered
- ❌ URL crawling is manual
- ❌ Fuzzing needs setup
- ❌ Results in random folders
- ❌ Copy-paste chaos

</td>
<td width="50%" valign="top">

### ⚡ The Solution

- ✅ **One script, full URL recon**
- ✅ **Subdomains + URLs + Fuzzing**
- ✅ **Clean aggregated output**
- ✅ **WAF detection included**
- ✅ **Automated pipeline**

</td>
</tr>
</table>

<div align="center">

**FTJIYANA** is a **Python-based URL reconnaissance framework** that chains subdomain enumeration, URL crawling, and directory fuzzing into one automated pipeline. **Perfect for bug bounty hunters who want clean URL lists fast.**

<br/>

> *"Stop wrestling with 10 tools. One script. All URLs. Done."*

</div>

<br/>

<div align="center">

<img src="https://user-images.githubusercontent.com/74038190/212284100-561aa473-3905-4a80-b561-0d28506553ee.gif" width="900" alt="divider"/>

## ✨ Features That Hit Different

</div>

<table align="center">
<tr>
<td align="center" width="25%">

### 🔍
### Subdomain Enumeration
`amass`, `subfinder`, `crtsh`, `assetfinder`, `findomain` — all chained.

</td>
<td align="center" width="25%">

### 🕷️
### URL Crawling
`gau`, `waybackurls`, `katana`, `gospider` — passive + active.

</td>
<td align="center" width="25%">

### 🎯
### Directory Fuzzing
`gobuster`, `ffuf`, `dirsearch` — fast, clean fuzzing.

</td>
<td align="center" width="25%">

### 🛡️
### WAF Detection
`wafw00f` + `whatweb` — identify defenses.

</td>
</tr>
<tr>
<td align="center">

### 🧹
### Clean Output
`subdomains.txt` + `urls.txt` — deduplicated, ready to use.

</td>
<td align="center">

### 📁
### Structured Raw
Every tool's output saved in `raw/`.

</td>
<td align="center">

### ⚡
### One Command
`python3 ftjiyana.py target.com` — that's it.

</td>
<td align="center">

### 🔎
### Probing
`httprobe`, `httpx` — live hosts filtered.

</td>
</tr>
</table>

## 🏗️ Architecture

</div>

<table align="center">
<tr>
<td width="100%">

| 🧩 Component | 📋 Purpose |
|---|---|
| `ftjiyana.py` | 🎯 Main entry point |
| `config/tools.json` | 🛠️ Tool registry |
| `core/` | 🧠 Core logic |
| `errors/` | 🩹 Error handling |
| `results/TARGET_TIMESTAMP/raw/` | 📁 Per-tool output |
| `results/TARGET_TIMESTAMP/subdomains.txt` | 🔍 All subdomains |
| `results/TARGET_TIMESTAMP/urls.txt` | 🕷️ All URLs |

</td>
</tr>
</table>

## 🚀 Quick Start

</div>

<table align="center">
<tr>
<td width="50%">

### 📦 Step 1 — Clone

**git clone https://github.com/BLOODRAVENIST/FTJIYANA.git**

**cd FTJIYANA**

</td>
<td width="50%">

### 🐍 Step 2 — Setup

**python3 -m venv venv**

**source venv/bin/activate**

**pip install -r requirements.txt**

</td>
</tr>
<tr>
<td width="50%">

### 🔧 Step 3 — Install Tools

**which subfinder gau katana**

Install missing tools via `go install` or `apt`.

</td>
<td width="50%">

### 🚀 Step 4 — Launch

**python3 ftjiyana.py example.com**

**That's it. URLs ready.**

</td>
</tr>
</table>

## 🛠️ Troubleshooting

</div>

<table align="center">
<tr>
<td width="50%">

| ❌ Issue | ✅ Fix |
|---|---|
| ModuleNotFoundError | `source venv/bin/activate && pip install -r requirements.txt` |

</td>
<td width="50%">

| ❌ Issue | ✅ Fix |
|---|---|
| Empty results | Check `results/*/raw/` for per-tool errors |
